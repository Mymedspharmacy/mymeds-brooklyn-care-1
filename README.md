# MyMeds Pharmacy Inc.

Modern pharmacy management system with e-commerce integration.

## Quick Start

```bash
# Frontend
npm run dev

# Backend (separate terminal)
cd backend && npm run dev
```

- Appointment booking system
- WooCommerce e-commerce integration
- Admin dashboard
- WordPress blog integration
